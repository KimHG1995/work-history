# 프로젝트 구조

[프로젝트 소개](README.md)로 돌아갑니다.

## 주요 폴더

전체 폴더를 나열하기보다 역할을 설명할 수 있는 폴더를 적습니다.

| 폴더 | 하는 일 | 내가 작업한 내용 |
| --- | --- | --- |
| [폴더 경로] | [담당하는 기능] | [수정하거나 만든 내용] |

## 구성 요소

| 이름 | 하는 일 | 연결된 대상 | 내가 맡은 부분 |
| --- | --- | --- | --- |
| [화면, 서버, 저장소 등의 이름] | [역할] | [연결된 요소] | [내 작업 범위] |

## 데이터가 오가는 순서

1. [어디서 어떤 요청이 시작되는지]
2. [요청을 어디서 어떻게 처리하는지]
3. [어떤 데이터를 읽거나 저장하는지]
4. [결과를 어디로 보내는지]

아래 그림은 양식용 예시입니다. 실제 구조에 맞게 바꾸거나 지웁니다.
Mermaid는 아래처럼 글로 적은 내용을 그림으로 보여주는 형식입니다.

```mermaid
flowchart LR
    user[사용자] --> screen[화면]
    screen --> server[서버]
    server --> data[데이터 저장소]
```

## 이 구조를 고른 이유

- 풀어야 했던 문제: [구조를 정하거나 바꾼 이유]
- 선택한 방법: [어떤 구조를 사용했는지]
- 고른 이유: [이 방법이 상황에 맞았던 이유]
- 다른 방법과 비교: [다른 방법을 쓰지 않은 이유 또는 해당 없음]
- 남은 어려움: [아직 해결하지 못한 문제나 제한]
