# 단기 구인구직 플랫폼 운영 개선

[전체 작업 목록](../README.md)으로 돌아갑니다.

기업과 개인을 위한 단기 구인구직 플랫폼에서 진행한 작업입니다.
2021-07 ~ 2024-01 근무 중 백엔드 개발과 인터널팀 리드를 맡았습니다.
회사 설명과 근무 정보는 [근무 기록](../../experience.md)에 정리했습니다.

## 작업 목록

| 작업 | 맡은 일 | 결과 |
| --- | --- | --- |
| [초기 관리자 페이지](initial-admin.md) | 관련 부서와 기능 정리, DB와 서버와 화면 단독 개발 | DB를 직접 수정하던 업무를 관리자 페이지에서 처리 |
| [급여 정산과 환불](settlement.md) | 약 한 달간 DB와 서버와 화면 단독 개발 | 지급과 환불을 내부 관리자 페이지에서 처리 |
| [관리자 화면과 API 개선](admin-improvement.md) | 인터널팀 리드, 기획과 API 수정, 전환 지원 | 기능별로 개선하고 운영에 반영 |
| [데이터 분석 환경과 대시보드](data-analytics.md) | DS와 구조 정리, 적재와 조회 환경 구성 | 원본 데이터 분석 환경 구축, 대시보드 반복 계산 부담 감소 |
| [자동 배포](deployment.md) | Bitbucket Pipelines 작성 | 개발은 자동 배포, 운영은 사람 승인 후 배포 |
| [이벤트 공통 코드 정리](event-system.md) | 백엔드 서버와 DB 개발 | 광고와 푸시, 지표 관련 코드를 비슷한 이벤트에 재사용 |

## 읽는 방법

각 작업 파일에 시작한 이유, 역할 분담, 기술, 처리 순서도와 결과를 함께 적었습니다.
관련 내용을 보완할 때는 해당 작업 파일을 수정합니다.

근무 기간은 각 작업의 개발 기간과 다릅니다. 정확한 작업 기간은 확인된 경우에만 적었습니다.
