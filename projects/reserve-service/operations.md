# 예비군 서비스 개발과 운영

[예비군 작업 목록](README.md)으로 돌아갑니다.

예비군 서비스의 웹과 서버를 함께 개발하고 운영하고 있습니다.

## 기본 정보

| 항목 | 내용 |
| --- | --- |
| 작업 기간 | 2025-11 ~ 현재 |
| 맡은 범위 | 프론트엔드와 백엔드 개발, 유지보수, 운영 이슈 대응 |
| 개발 상태 | 개발과 유지보수 중 |
| 운영 상태 | 운영 중 |

## 왜 시작했는지

운영 중인 예비군 서비스에 지속적으로 요구사항을 반영해야 했습니다.
화면과 서버의 기능 흐름을 연결하고 기존 서비스를 유지하며 개선할 필요가 있었습니다.

## 기술 스택

| 구분 | 기술 |
| --- | --- |
| 프론트엔드 | React |
| 백엔드 | Node.js |
| 데이터베이스 | MySQL |
| 인프라 | NCP |

## 어떻게 해결했는지

- React 웹과 Node.js 서버의 풀스택 기능 개발
- 운영팀 요청을 반영한 기능 추가와 개선
- 기존 코드 유지보수와 운영 이슈 대응
- 화면부터 서버, DB까지 연결되는 기능 흐름 정리

## 업무 흐름

```mermaid
flowchart LR
    request["운영팀 요구사항 확인"] --> develop["웹과 서버 기능 개발 및 개선"]
    develop --> service["서비스 반영"]
    service --> operation["유지보수와 운영 이슈 대응"]
```

## 결과와 현재 상태

실제 운영 흐름에 맞춰 웹과 서버 기능을 개선하고 있습니다.
운영 요구사항 반영과 유지보수를 계속 맡고 있습니다.
