# 민방위 서비스 개발과 운영

[민방위 작업 목록](README.md)으로 돌아갑니다.

NCP 환경에서 민방위 서비스의 백엔드 개발과 운영을 맡고 있습니다.

## 기본 정보

| 항목 | 내용 |
| --- | --- |
| 참여 기간 | 2025-11 ~ 현재 |
| 맡은 범위 | 백엔드 기능 개발, API 개선, 운영 이슈 대응 |
| 상태 | 개발과 운영 중 |

## 왜 시작했는지

공공 서비스 운영 기준과 기존 인프라 환경을 유지하면서 운영팀 요구사항을 반영해야 했습니다.
API와 데이터 처리 방식이 일관되도록 기존 구조를 정리할 필요가 있었습니다.

## 기술 스택

| 구분 | 기술 |
| --- | --- |
| 언어와 서버 | TypeScript, NestJS |
| 데이터베이스 | MySQL, TypeORM |
| 인프라 | NCP |
| 운영 스크립트 | Python, Bash |

## 맡은 작업

- 운영팀 요청을 반영한 백엔드 기능 개발
- 기존 코드 개선과 API 정비
- 데이터 접근 방식과 응답 형식 정리
- NCP 환경의 서비스 운영과 이슈 대응

운영 중인 서비스에 필요한 기능을 추가하고 기존 서버 구조를 개선하고 있습니다.
예약 메시지, 출결과 예약 동시 요청 개선은 각각의 작업 문서에 정리했습니다.
