# PaperTrail 전자문서 생성과 증적 플랫폼

[전체 작업 목록](../README.md)으로 돌아갑니다.

업무 시스템이 JSON만 전달하면 버전이 고정된 템플릿으로 문서를 비동기 생성하고, 생성 당시 입력과 템플릿, 결과 해시를 남겨 재현성과 감사 추적을 지원하는 문서 인프라 사이드 프로젝트입니다.
