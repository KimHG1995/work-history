# AI 그림 심리검사 서비스 개편

[교육 서비스 작업 목록](README.md)으로 돌아갑니다.

기존 Java Spring 서버의 불필요한 코드를 정리하고 NestJS와 Drizzle 기반으로 다시 설계했습니다. 서비스마다 검사 기능을 따로 만들지 않고 공통 서버를 연동해 사용할 수 있도록 구성했습니다.

개발 서버 배포: 2025-03-04.

## 왜 시작했는지

- 기존 Java Spring 서버는 기능 범위가 제한되어 새 요구사항을 반영하기 어려웠다.
- 불필요한 코드를 줄이고, 여러 서비스가 같은 검사 기능을 사용할 수 있게 구조를 바꿀 필요가 있었다.
- 짧은 일정 안에 서버를 전환하고 운영 가능한 상태로 만들어야 했다.

| 구분 | 기술 |
| --- | --- |
| 언어 | TypeScript |

SQS의 구체적인 처리 대상은 확인 필요입니다.

## 어떻게 해결했는지

- 기존 Java Spring 서버의 기능과 코드를 분석하고, 불필요한 코드를 줄이며 NestJS와 Drizzle 기반으로 전환했다.
- 검사 기능을 업무별 모듈로 나누고, 여러 서비스에서 연동해 사용할 수 있도록 공통 서버 구조를 설계했다.
- 환경별 설정과 배포 구성을 정리하고, 따로 처리해야 하는 작업에 SQS를 연결했다.
- 검사 종류에 따라 질문 묶음, 질문 내용과 순서, 선택지를 구분해 관리하도록 정리했다.

질문의 최종 DB 저장 방식은 확인 필요입니다.

## 서버 구성


## 결과와 현재 상태

- Java Spring 서버를 NestJS 기반으로 전환하고 여러 서비스가 활용할 공통 구조를 마련했다.
- 2025-03-06 운영 서버에 배포하고 실제 서비스 운영까지 진행했다.
- 한 서비스 메서드에 처리 로직과 예외 처리가 집중된 문제가 남아 있다.
- 메서드를 역할별로 나누는 추가 개선의 완료 여부는 확인 필요다.
