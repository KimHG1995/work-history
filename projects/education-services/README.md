# 교육 서비스 개발과 운영 개선

[전체 작업 목록](../README.md)으로 돌아갑니다.

에듀테크 기업의 계열사에서 진행한 회사 프로젝트입니다.
2024-01 ~ 2025-10 동안 백엔드 개발을 맡았으며 직급은 대리였습니다.
회사와 근무 정보는 [근무 기록](../../experience.md#에듀테크-기업-계열사)에 정리했습니다.

## 작업 목록

| 작업 | 요약 |
| --- | --- |
| [쿠폰 이벤트 시스템](promotion.md) | 쿠폰 구조를 템플릿과 이벤트 기반으로 바꾸고, 관리자 풀스택 개발과 서버, DB 설계를 맡았습니다. |
| [AI 심리검사 서비스 개편](assessment-renewal.md) | Java Spring 서버를 NestJS와 Drizzle로 전환해 여러 서비스가 사용할 공통 서버를 만들고 운영에 배포했습니다. |
| [통합 알림 시스템](notifications.md) | 공통 발송과 이력 추적, 배포 자동화를 구현하고 운영 서버에 배포했습니다. |
| [미술 교육 서비스 개편](art-service-renewal.md) | Java 서버를 NestJS와 Prisma로 전환하고 관리자 페이지와 대시보드를 만들었습니다. |
| [개인 고객 서비스 관리자 페이지](b2c-admin.md) | 인수한 프로젝트의 구조를 정리하고 수업, 출석, 사용자 등급 관리 기능을 개발했습니다. |
| [개인 고객 수강 앱 서버](class-app-server.md) | 중단된 프로젝트를 인수해 1:1 수업 예약부터 종료와 출결까지 서버 기능을 정리했습니다. |

목록 순서는 작업의 시작 순서를 뜻하지 않습니다. 작업 기간과 운영 상태는 각 작업에서 확인할 수 있습니다.
