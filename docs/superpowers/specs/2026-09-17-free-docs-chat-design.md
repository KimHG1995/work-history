# 무료 문서 질문 봇 설계

현재 공개된 경력 Markdown을 검색해 관련 내용을 답하고 원문 링크를 제공한다. AI API와 서버는 무료 요금제만 사용한다. 한도를 초과하면 AI 호출을 중단하고 문서 검색 결과를 제공한다.

상태: 설계 완료. 봇 구현과 배포는 아직 진행하지 않음.

## 구성

- 화면: 기존 GitHub Pages와 VitePress에 질문 패널 추가.
- API: Cloudflare Workers Free.
- 한도 저장: Workers Free에서 지원하는 SQLite 기반 Durable Object. 하나의 객체에서 전체 한도와 진행 중인 요청을 관리한다.
- AI: OrcaRouter의 가격이 0인 무료 모델 하나만 지정한다. 초기 후보는 `deepseek/deepseek-v4-flash-free`.
- 자료: `experience.md`, `timeline.md`, `projects/`의 공개 문서만 사용한다.
- API 키: Worker Secret에 저장한다. 브라우저, Git, 로그에 포함하지 않는다.

브라우저에서 직접 호출하면 API 키가 노출된다. Worker의 메모리나 지역별 요청 제한만으로 전체 일일 한도를 계산하면 여러 서버에서 중복 허용할 수 있어, 전역 카운터는 Durable Object에서 관리한다. 유료 벡터 DB와 임베딩 API는 사용하지 않는다.

## 요청 한도

아래 값은 이 사이트에서 적용할 초기 정책이다. OrcaRouter의 제공 한도와 구분한다.

| 항목 | 제한 | 처리 |
| --- | --- | --- |
| 전체 순간 요청 | 초당 AI 호출 시작 1회, 추가 버스트 없음 | 429와 Retry-After 반환 |
| 전체 분당 요청 | 최근 60초 동안 AI 호출 최대 8회 | 429와 Retry-After 반환 |
| 전체 일일 요청 | AI 호출 최대 40회 | 한국 시간 오전 9시에 초기화 |
| 방문자 연속 요청 | 같은 IP는 10초에 AI 호출 1회 | 남은 대기 시간 안내 |
| 방문자 분당 요청 | 같은 IP에서 최근 60초 동안 최대 3회 | 429와 Retry-After 반환 |
| 방문자 일일 요청 | 같은 IP에서 AI 호출 최대 10회 | 한국 시간 오전 9시에 초기화 |
| 전체 동시 처리 | AI 호출 최대 2건 | 대기열 없이 거절 |
| 동일 질문 재전송 | 같은 IP에서 같은 질문을 60초 안에 반복 | AI 재호출 없이 기존 결과 또는 진행 상태 안내 |
| 요청 본문 | 최대 4KB | 초과 시 413 |
| 질문 길이 | 최대 500자 | 초과 시 400 |
| AI 응답 대기 | 최대 30초 | 시간 초과 시 중단하고 문서 링크 제공 |
| AI 출력 | 최대 512토큰 | 짧은 답변과 원문 링크 제공 |
| 자동 재시도 | 없음 | 사용자가 대기 시간 이후 다시 요청 |

여기서 초당 제한은 API 요청 시작 횟수다. AI가 초당 생성하는 토큰 수인 TPS와는 다르다. 토큰 생성 속도는 제공자가 결정하며, 이 서비스는 요청 수, 입력 길이, 출력 토큰과 동시 처리 수를 제한한다.

방문자 구분은 Cloudflare가 제공하는 접속 IP를 서버에서 일별 HMAC으로 변환해 사용한다. 사용자가 보낸 임의 IP 헤더는 신뢰하지 않는다. 원본 IP와 질문 전문은 한도 기록에 저장하지 않는다. 같은 회사나 가정에서 IP를 공유하면 한도도 공유하며, IP를 바꾸는 수집기를 완전히 막는 인증 수단은 아니다.

## 한도 계산

1. 본문 크기, 질문 길이, 허용 출처를 검사한다.
2. 허용된 공개 문서에서 관련 부분을 검색한다. 관련 문서가 없으면 AI를 호출하지 않는다.
3. 동일 질문의 진행 상태나 기존 결과가 있으면 재호출하지 않는다. 완료 결과 캐시는 최대 60초, 최근 100개로 제한한다.
4. 무료 모델 가격과 계정 사용 조건을 확인한다.
5. Durable Object에서 전체 한도, IP별 한도와 동시 처리 자리를 한 번에 검사하고 예약한다.
6. 허용된 요청만 OrcaRouter로 보낸다. 외부 호출 직전부터 사용량에 포함하며 실패와 시간 초과도 차감한다.
7. 완료 시 동시 처리 자리를 해제한다. 중단된 요청 때문에 자리가 남지 않도록 45초 후 예약도 만료시킨다.

분당 한도는 최근 60초의 호출 시각으로 계산한다. 일일 카운터는 UTC 00:00, 한국 시간 09:00 기준이다. 객체 재시작이나 배포로 카운터를 초기화하지 않는다. 여러 한도를 동시에 넘으면 모두 통과할 수 있는 가장 늦은 시간을 Retry-After로 반환한다. 저장소 오류가 나면 AI 호출을 허용하지 않는다.

거절된 요청과 로컬 문서 검색은 AI 호출량에 포함하지 않지만 Cloudflare 요청량은 사용한다. 대량 요청으로 무료 서버 한도가 소진되면 봇이 멈출 수 있으며 기존 정적 문서 사이트는 계속 이용한다.

## 비용 방지

- Cloudflare Workers Free 요금제인지 배포 전에 확인한다. 유료 요금제로 전환하거나 추가 상품을 결제하지 않는다.
- 무료 모델의 실제 카탈로그 가격이 0인지 호출 전에 확인한다. 가격 검증 실패, 모델 제거, 유료 변경 시 중단한다.
- 브라우저가 모델, API 주소, 메시지 역할, 도구 설정을 지정할 수 없도록 한다.
- `orcarouter/auto`, 유료 폴백, 웹 검색, 도구 호출과 유료 임베딩을 사용하지 않는다.
- OrcaRouter 충전과 자동 충전을 설정하지 않는다. 유료 계정의 잔액을 이용하는 경로도 만들지 않는다.
- 제공자의 무료 한도가 더 낮아지면 더 낮은 한도를 따른다. 자동으로 사용량 한도를 올리지 않는다.
- 제한 응답과 모델 오류 발생 시 유료 모델로 전환하지 않고 문서 검색 결과로 대체한다.

현재 공개 API는 무결제 계정에 분당 10회와 하루 50회를 안내한다. 이 봇의 8회와 40회는 여유를 둔 값이며 같은 워크스페이스의 다른 사용량까지 확보해 주는 예약은 아니다. 제공 한도와 무료 모델은 변경될 수 있다.

## 문서 기반 답변과 보안

- 빌드 시 Markdown을 제목과 단락으로 나눠 검색 자료를 만든다. 문서 수정과 함께 갱신한다.
- Downloads 원본, 작성 규칙, 보안 설정, Secret과 비공개 자료는 검색 대상에서 제외한다.
- 관련 부분만 전달하며, 초기 상한은 문서 발췌 2,000자와 최근 질문 한 건이다. 무료 입력 제한을 넘으면 발췌를 더 줄이거나 문서 검색으로 대체한다.
- 질문과 관련 문서 발췌가 OrcaRouter와 모델 제공자에게 전송된다는 안내를 질문 화면에 표시한다.
- 문서 내용은 자료로 취급하며 그 안의 지시를 실행하지 않는다. 도구 실행, URL 가져오기, 파일 쓰기는 제공하지 않는다.
- 문서에 없는 내용은 없다고 답하고, 확인한 내용에는 원문 링크를 붙인다.
- AI 답변은 텍스트로 표시한다. HTML과 스크립트를 실행하지 않으며, 문서 링크는 서버가 가진 허용 목록에서만 만든다.
- 허용 Origin을 검사하되 이를 인증이나 봇 차단으로 간주하지 않는다. 서버 한도 검사는 별도로 적용한다.
- 기존 CSP에는 배포한 Worker의 정확한 주소만 추가한다.
- Clarity에서 질문 입력과 답변 영역을 마스킹한다. 질문과 답변 전문을 서버 로그에 남기지 않는다.

## 오류와 화면 동작

| 상황 | 동작 |
| --- | --- |
| 제한 초과 | 남은 대기 시간과 관련 문서 표시 |
| 관련 문서 없음 | 자료에 없는 내용이라고 안내, AI 호출하지 않음 |
| 무료 모델 이용 자격 미충족 | 봇 이용 불가와 문서 검색 안내 |
| 입력 길이 제한 | 질문을 줄이도록 안내 |
| 외부 API 오류 또는 시간 초과 | 자동 재시도 없이 관련 문서 표시 |
| 요금 확인 실패 | AI 호출 중단, 문서 검색 안내 |

## 검증 기준

- 동시에 요청해도 전체와 IP별 한도, 동시 처리 수를 넘지 않는다.
- 실패한 외부 호출도 카운터에 남고, 거절된 요청은 AI를 호출하지 않는다.
- UTC 날짜 경계, 서버 재시작, 예약 만료 후에도 한도가 유지된다.
- 모델 가격이 0이 아니거나 검증 불가이면 외부 생성 API 호출이 없다.
- 키가 브라우저 번들, Git 변경 내역과 로그에 포함되지 않는다.
- 문서 밖 질문, 악성 지시와 HTML 응답을 안전하게 처리한다.
- CSP, 문서 검색, 모바일 화면과 Clarity 마스킹을 브라우저에서 확인한다.
- 무료 계정으로 한 번 호출해 응답과 청구 금액 0을 확인한 후 공개한다.

## 배포 준비

- OrcaRouter 계정과 Cloudflare 계정은 보유 중이다.
- 이 컴퓨터의 Wrangler는 로그인되지 않은 상태다. Cloudflare 계정 연결이 필요하다.
- OrcaRouter API 키는 배포 시 Worker Secret으로 등록한다. 채팅에 키를 붙여 넣지 않는다.
- Cloudflare 무료 요금제와 OrcaRouter 무료 모델 접근 권한을 확인한 후 배포한다.
