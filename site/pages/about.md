# 사이트 소개

백엔드 개발 과정에서 마주한 문제, 설계 판단, 구현 과정과 결과를 정리한 기술 포트폴리오입니다. 회사 및 사이드 프로젝트별 역할 분담, 기술 스택, 검증 근거와 운영 상태를 확인할 수 있습니다.

## AI 질문 기능

프로젝트나 기술에 대해 질문하면 공개 경력 문서에서 관련 내용을 찾아 요약하고 원문 링크를 제공합니다.

공개 문서 검색 결과를 컨텍스트로 활용하는 LLM 질문 기능입니다. 질문의 핵심 키워드와 문서 제목, 분류, 본문을 비교해 관련 구간을 선택하며 임베딩이나 벡터 DB는 사용하지 않습니다.

```mermaid
flowchart TB
    question["사용자 질문"] --> index["공개 문서 인덱스"]
    index --> search["키워드와 문서 정보로<br/>관련 구간 검색"]
    search --> context["관련 문서로<br/>컨텍스트 구성"]
    context --> llm["LLM에 질문과 컨텍스트 전달"]
    llm --> answer["답변과 관련 문서 링크 제공"]
```
