# 개인정보와 외부 서비스 안내

최종 수정일: 2026-10-01

## 방문 분석

Microsoft Clarity를 사용해 클릭, 스크롤 등 페이지 이용 정보를 분석합니다. 이 과정에서 쿠키와 식별자가 사용될 수 있습니다. 질문 창의 내용은 Clarity 기록에서 가리도록 설정되어 있습니다.

브라우저 설정에서 쿠키를 제한하거나 삭제할 수 있습니다. 쿠키를 차단해도 문서는 읽을 수 있습니다. 자세한 내용은 [Microsoft 개인정보처리방침](https://www.microsoft.com/privacy/privacystatement)과 [Clarity 개인정보 안내](https://learn.microsoft.com/en-us/clarity/faq#privacy)를 확인해 주세요.

## AI 질문 기능

AI 답변을 요청하면 질문과 관련 공개 문서 일부가 Cloudflare Worker를 거쳐 OrcaRouter로 전송됩니다. 이름, 연락처, 비밀번호, API 키 등 개인정보나 비밀값은 입력하지 마세요.

요청 횟수를 제한하기 위해 접속 IP를 날짜별 식별값으로 변환해 사용합니다. 한도 기록에는 IP 원문과 질문을 저장하지 않습니다. 외부 서비스의 정보 처리와 보관에는 각 서비스의 정책이 적용됩니다.

## 브라우저 저장과 외부 링크

화면 테마 같은 표시 설정은 브라우저에 저장될 수 있습니다. 외부 링크로 이동하면 해당 서비스의 개인정보 처리 기준이 적용됩니다.
