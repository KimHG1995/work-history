# 개인정보와 외부 서비스 안내

최종 수정일: 2026-09-28

이 사이트는 공개된 개발 경험과 프로젝트 문서를 제공하는 개인 사이트입니다. 회원가입이나 사이트 자체의 결제 기능은 제공하지 않습니다.

## 방문 분석

사이트 이용을 살펴보기 위해 Microsoft Clarity를 사용합니다. 클릭과 스크롤 등 페이지 이용 정보가 분석에 사용될 수 있으며, 이 과정에서 쿠키와 관련 식별자가 사용될 수 있습니다. 질문 창은 Clarity 마스킹 대상으로 설정되어 있습니다.

브라우저 설정에서 쿠키를 제한하거나 삭제할 수 있습니다. 자세한 정보는 [Microsoft 개인정보처리방침](https://www.microsoft.com/privacy/privacystatement)과 [Clarity 개인정보 안내](https://learn.microsoft.com/en-us/clarity/faq#privacy)를 확인해 주세요. 쿠키를 차단해도 문서 본문은 읽을 수 있습니다.

## 질문 기능

질문을 제출하면 브라우저가 공개 문서에서 관련 내용을 찾습니다. AI 기능을 사용할 수 있으면 질문을 Cloudflare Worker로 전송하고, Worker가 질문과 관련 공개 문서 일부를 OrcaRouter에 전달해 답변을 요청합니다.

요청 한도를 관리하기 위해 Worker는 요청 IP를 날짜별 HMAC 값으로 변환해 사용합니다. IP 원문과 질문을 한도 기록에 저장하지 않도록 구성되어 있습니다. 이러한 설정이 외부 서비스의 모든 로그나 보관 정책을 없앤다는 뜻은 아닙니다.

이름, 연락처, 계정 비밀번호, API 키 등 개인정보나 비밀값은 질문에 입력하지 마세요. AI 기능이 연결되지 않거나 문서 버전이 다르면 외부 모델을 호출하지 않고 관련 문서 링크를 제공합니다.

## 광고 도입 상태

현재 광고 송출 코드는 활성화되어 있지 않습니다. 사이트 소유권 확인을 위한 메타 태그나 판매자 확인 파일만 준비할 수 있으며, 이러한 파일만으로 광고를 요청하지는 않습니다.

Google AdSense 광고를 활성화하기 전에는 광고와 쿠키 사용 안내를 실제 구성에 맞게 갱신하고 필요한 동의 절차를 적용합니다. 광고 승인과 동의 처리가 끝났다고 미리 간주하지 않습니다.

## 브라우저 저장과 외부 링크

화면 테마 같은 표시 설정은 브라우저에 저장될 수 있습니다. 외부 링크로 이동한 뒤에는 해당 서비스의 개인정보 처리 기준이 적용됩니다. 보관 기간과 정보 처리 조건은 각 서비스의 정책과 실제 운영 설정을 확인해야 합니다.
